# Benchmarking World Models for Continual Learning on Compositional Tasks

This repository hosts the project [webpage](https://object814.github.io/Compositional-Continual-Learning/) for the paper **“Benchmarking World
Models for Continual Learning on Compositional Tasks.”** The website presents
the benchmark design, experimental setup, main results, reuse analysis, and an
appendix containing metric definitions, numerical results, and full training
curves.
